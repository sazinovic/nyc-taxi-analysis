# NYC Yellow Taxi Analysis

End-to-end analysis of New York City Yellow Taxi trip data using Python.

## Overview

This project analyzes NYC Yellow Taxi trip records to explore
travel patterns, trip demand, fares, and passenger behavior.

The analysis includes data cleaning, exploratory data analysis (EDA),
feature engineering, and data visualization.

## Dataset

- **Source:** NYC Taxi & Limousine Commission (TLC)
- **Dataset:** Yellow Taxi Trip Records
- **Period:** January 2026
- **Format:** Apache Parquet

Official dataset:
https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
